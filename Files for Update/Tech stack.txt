Good if you also manage lots of images.

Very scalable.

50. One final architectural recommendation

Since you already have a Next.js frontend + Node.js backend + MongoDB, don't let an AI coding agent decide to replace your stack with something completely different.

Your project brief should explicitly say:

Preserve the existing Next.js frontend architecture wherever practical. Preserve the existing Node.js + MongoDB ecosystem. Refactor only where necessary. Do not migrate to PostgreSQL, Firebase, Supabase or another backend/database unless explicitly approved.

Then tell it to audit the current code before modifying anything.

That's particularly important because you also want to remove the existing Render service. The agent needs to determine whether that service is actually used by the current website or another application before removing it.

The ideal end state is therefore:
